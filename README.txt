README VERSION 1.1 // OCTOBER 7TH 2026
---------------------------------------------------------------------------------------
Hello! This is a slightly updated version of my bare-bones website, now featuring a working palette choice feature!! The palette choices are still ugly as can be, but the functionality is there B)

In order to get the feature to work, I found some information from W3 schools about localStorage, and how that works. From there, I did some other research on how I can use this for my purposes. With a bit of debugging help from ChatGPT, I was able to get it to work in the most simple of ways. I admit I only understand like 75% of HOW it works, because the idea of local storage and site data and cookies sound like witchcraft to me. HOW it works is magic in my mind, but ***what I have to tell it to do to make it work*** makes sense to me, and I'm gonna call that good enough for now.


REFERENCES ON LOCALSTORAGE:

https://www.w3schools.com/jsreF/prop_win_localstorage.asp

https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage

https://meticulous.ai/blog/localstorage-complete-guide/#performing-operations-on-localstorage
